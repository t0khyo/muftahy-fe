# @workspace/ui

## Overview

Shared UI component library for the Muftahy frontend. Contains shadcn/ui components built on Base UI primitives, configured with the `base-nova` preset, RTL enabled (`"rtl": true` in `components.json`), and Tailwind CSS v4 with a comprehensive semantic design-token system defined in `src/styles/globals.css`. Fonts: Inter Variable (Latin) and Tajawal (Arabic). Components must not be edited by hand — use the shadcn CLI.

## Interface

- `@workspace/ui/components/*` — all UI components (see `src/components/README.md` for the full list)
- `@workspace/ui/lib/utils` — `cn()` class-name merger
- `@workspace/ui/globals.css` — Tailwind base + all CSS custom properties (design tokens for light and dark themes)

## Invariants

- No imports from other workspace packages (`@workspace/domain`, `@workspace/api`, etc.). This is a leaf dependency.
- Semantic tokens only; no raw hex or arbitrary Tailwind values in component files.
- RTL-compatible logical CSS properties used throughout.
- Components are generated by the shadcn CLI; hand-edits will be overwritten on next `shadcn add`.

## Side Effects

- `Dialog` and `Sheet` components use Base UI portals (render into `document.body`).
- CSS custom properties in `globals.css` are set on `:root` and `.dark`; they affect the entire document.
