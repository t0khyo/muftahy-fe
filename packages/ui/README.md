# @workspace/ui

## Overview

Shared UI component library for the Muftahy frontend. Contains shadcn/ui components built on Base UI primitives, configured with the `base-nova` preset, RTL enabled (`"rtl": true` in `components.json`), and Tailwind CSS with semantic design tokens defined in `src/styles/globals.css`.

## Interface

- src: [./src/README.md](./src/README.md) - Component source root containing primitives and utility helpers
- `@workspace/ui/components/*` — shadcn/Base UI components
- `@workspace/ui/lib/utils` — `cn()` class-name merger
- `@workspace/ui/globals.css` — Tailwind base design tokens and theme CSS custom properties

## Invariants

- No imports from other workspace packages (`@workspace/domain`, `@workspace/api`, etc.). Leaf dependency in the monorepo graph.
- Semantic tokens only; no raw hex or arbitrary Tailwind values in component files.
- RTL-compatible logical CSS properties used throughout.
- Components are generated by shadcn CLI; manual hand-edits are prohibited.

## Side Effects

- `Dialog` and `Sheet` components use Base UI portals (render into `document.body`).
- CSS custom properties in `globals.css` are set on `:root` and `.dark`, affecting the root document styling.
