# domain/src

## Overview

Source root for the `@workspace/domain` package, grouping core domain data schemas and formatting utilities.

## Subdirectories & Boundaries

- formatters: [./formatters/README.md](./formatters/README.md) - `Intl`-based money, number, and date formatters enforcing Western digits
- schemas: [./schemas/README.md](./schemas/README.md) - Zod schemas and inferred TypeScript types for all core domain entities
